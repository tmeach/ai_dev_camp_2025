# WebSocket Events

## Client → Server
1. `join-room` - войти в комнату
2. `code-change` - изменить код  
3. `language-change` - сменить язык
4. `execute-code` - выполнить код

## Server → Client  
1. `code-update` - обновление кода
2. `user-joined` - пользователь присоединился
3. `execution-result` - результат выполнения
