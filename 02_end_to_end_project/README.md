# Online Code Interview Platform - Frontend

Реалтайм платформа для проведения технических собеседований с синхронизацией кода.

## 🚀 Быстрый старт

### Предварительные требования
- Node.js 16+ и npm

### Установка и запуск

```bash
# 1. Клонируйте репозиторий
git clone <repository-url>
cd online-interview-platform

# 2. Установите зависимости
npm install

# 3. Создайте файл .env
echo "VITE_SOCKET_SERVER_URL=http://localhost:3001" > .env

# 4. Запустите dev сервер
npm run dev
